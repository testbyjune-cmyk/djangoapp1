Vercel에서 데이터를 저장할 때는 파일이냐, 짧은 텍스트/키-값 데이터냐에 따라 쓰는 스토리지가 다릅니다. 참고로 Vercel KV는 이제 Vercel이 직접 서비스하지 않고 파트너사인 Upstash Redis 기반 마켓플레이스로 전환되었고, Vercel Blob은 Vercel 자체 스토리지로 계속 운영되고 있습니다.

1. Vercel Blob — 이미지·파일·미디어 저장용

이미지, PDF, 동영상 등 일반적인 파일을 저장할 때 사용합니다.

구분무료(Hobby) 플랜유료(Pro) 플랜
저장 용량1 GB기본 제공 없음 / GB당 $0.023 / 월

개인 블로그·토이 프로젝트용 이미지/파일 저장소로는 1GB 용량과 월 10GB 전송량이 꽤 넉넉합니다. 무료 플랜은 제한을 초과해도 결제되지 않고, 해당 월의 기능이 일시 정지됩니다.

2. Vercel KV (Upstash Redis 기반) — Key-Value 데이터 저장용

JSON 형태의 간단한 데이터, 세션, 방문자 수 같은 텍스트 데이터를 담는 메모리 기반 Key-Value 저장소입니다.

구분무료(Hobby / Upstash Free)유료(Pro / 사용량 비례)
저장 용량256 MBGB당 $0.25 / 월
일일 명령어 (API 요청)하루 10,000회10만 회당 $0.20
단일 Key/Value 크기최대 100 MB최대 100 MB

256MB가 작아 보일 수 있지만, 순수 텍스트/JSON 데이터만 저장한다면 몇십만 건의 텍스트를 담기에 충분합니다.

💡 한눈에 보는 요약 및 추천
  • 이미지/파일/문서를 저장하고 싶다 → Vercel Blob (1GB 무료 제공)
  • 간단한 JSON/텍스트 데이터를 DB처럼 쓰고 싶다 → Vercel KV(Upstash) (256MB 무료 제공)
  • 무료 용량을 다 쓰면? Hobby는 추가 요금 없이 해당 월 기능이 잠시 멈추고, Pro는 초과분만큼 온디맨드로 소액 청구됩니다.

이 데모에 적용된 닐슨 10원칙

1. 시스템 상태의 가시성글자 수 카운터, 무료 한도 시뮬레이션 바, "저장 중..." 버튼 상태
2. 시스템-현실 일치채팅/댓글창과 같은 익숙한 입력-목록 구조, "n분 전" 상대 시간 표시
3. 사용자 제어와 자유내가 남긴 문장만 삭제 가능, "지우기" 버튼으로 입력 즉시 취소
4. 일관성과 표준사이트 전체와 동일한 Bootstrap 버튼/카드 스타일 재사용
5. 오류 예방빈 문장·280자 초과 시 등록 버튼 자체가 비활성화
6. 기억보다 인지글자 제한(280자)과 예시 placeholder를 입력창에 항상 노출
7. 유연성과 효율성Enter로 즉시 등록, Shift+Enter로 줄바꿈
8. 미학적·미니멀 디자인불필요한 장식 없이 입력창 → 목록 순의 단순한 흐름
9. 오류 인식·복구실패해도 입력한 문장을 지우지 않고 원인을 문장으로 안내
10. 도움말/문서입력창 위에 이 데모가 KV/Blob 중 무엇을 흉내내는지 바로 설명

※ 위 무료 한도 바는 실제 Upstash 사용량을 조회하는 것이 아니라, 이 데모의 누적 문장 수를 KV 일일 한도(10,000회)에 빗대어 보여주는 교육용 시뮬레이션입니다.

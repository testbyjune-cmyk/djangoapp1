Claude Code는 "에이전트" 방식으로 동작합니다. 요청을 한 번에 다 풀지 않고, 도구 호출 → 결과 관찰 → 다음 행동 결정을 반복하며 스스로 계획을 조정합니다.

핵심 개념

  • 메인 에이전트: 사용자와 직접 대화하며 전체 작업을 조율합니다.
  • 서브에이전트(Subagent): 메인 에이전트가 독립적인 하위 작업을 위임하는 별도의 실행 단위입니다. 서브에이전트는 자기 컨텍스트 안에서 조사를 마친 뒤, 요약된 결과만 메인 에이전트에게 돌려줍니다.
  • 왜 위임하나요?: 코드베이스 전체를 뒤지는 것 같은 큰 조사를 서브에이전트에게 맡기면, 방대한 중간 검색 결과가 메인 대화의 컨텍스트를 차지하지 않습니다. 메인 에이전트는 "결론"만 받아 깔끔하게 이어갑니다.
  • 대표 유형 예시: 읽기 전용 탐색에 특화된 유형, 설계/계획에 특화된 유형, 범용 유형 등 — 유형마다 사용할 수 있는 도구 범위가 다르게 구성됩니다.

언제 위임할까?

  • 여러 파일/여러 단계를 거쳐야 하는 열린 질문의 조사
  • 서로 독립적이라 병렬로 처리해도 되는 작업
  • 중간 결과가 방대해서 메인 컨텍스트에 남기고 싶지 않은 검색

반대로 대상이 이미 명확한 파일 하나를 수정하는 등 간단한 작업은 위임 없이 메인 에이전트가 바로 처리하는 것이 더 빠릅니다.

서브에이전트는 어떻게 정의하나요?

서브에이전트는 .claude/agents/<이름>.md 파일 하나로 정의합니다. YAML 프런트매터에 이름·설명·사용 가능 도구·모델을 적고, 본문에는 이 에이전트 전용 시스템 프롬프트를 씁니다. 특히 description은 메인 에이전트가 "지금 이 작업을 누구에게 맡길지" 판단하는 핵심 단서이므로 구체적으로 적을수록 좋습니다. 

---
name: code-reviewer
description: 코드가 수정된 직후 반드시 사용. 버그·스타일·보안 이슈를 점검하는 리뷰 전문가.
tools: Read, Grep, Glob, Bash
model: opus
---

당신은 신중한 시니어 코드 리뷰어입니다. 변경된 부분을 읽고
정확성, 일관성, 보안 취약점 순으로 점검한 뒤 우선순위가 매겨진
피드백 목록을 반환하세요. 사소한 스타일 지적으로 핵심 이슈를 묻지 마세요.
  • tools를 생략하면 메인 에이전트가 가진 모든 도구를 상속합니다 — 필요한 도구만 최소로 나열하면 실수로 파일을 쓰거나 지우는 사고를 예방할 수 있습니다.
  • model을 생략하면 기본 모델을 사용합니다. 정밀한 판단이 필요한 리뷰어는 상위 모델을, 단순 탐색은 빠른 모델을 지정하기도 합니다.

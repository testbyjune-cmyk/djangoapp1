Git worktree는 하나의 저장소(.git)를 공유하면서, 여러 개의 독립된 작업 디렉터리를 동시에 체크아웃할 수 있게 해줍니다. 브랜치를 바꾸려고 현재 작업을 stash 할 필요가 없습니다.

핵심 개념

  • 메인 작업트리: 평소 작업하는 폴더. 지금 보고 있는 파일들이 여기 있습니다.
  • 워크트리(격리 공간): 별도 브랜치를 가리키는 또 다른 폴더. 여기서 변경해도 메인 작업트리는 전혀 영향받지 않습니다.
  • 왜 필요한가: 위험하거나 실험적인 변경(대규모 리팩터링, 여러 대안 비교)을 시도할 때, 현재 작업 내용을 건드리지 않고 안전하게 실험한 뒤 마음에 들면 병합할 수 있습니다.
  • 병렬 작업: 서로 다른 작업트리에서 독립적인 작업을 동시에 진행할 수 있어, 여러 실험을 병렬로 돌릴 수 있습니다.

직접 해보기: 격리 모드 켜고 끄기

아래 스위치를 눌러 "격리 모드"를 켜면, 변경 사항이 메인 작업트리와 분리된 별도 공간에서 일어나는 모습을 볼 수 있습니다.

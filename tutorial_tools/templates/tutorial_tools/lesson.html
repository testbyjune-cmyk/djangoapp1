Claude Code는 만능 셸 하나가 아니라, 목적별로 나뉜 전용 도구를 사용합니다. 전용 도구는 결과가 더 예측 가능하고, 실수를 미리 막아줍니다.

상황 → 추천 도구

하고 싶은 일도구왜
파일 하나의 전체 내용 보기Read파일 읽기에 특화, 줄 번호 포함 출력
기존 파일의 일부만 수정Edit정확한 부분만 치환, 전체 재작성 방지
새 파일 작성Write새로 만들거나 완전히 덮어쓸 때만 사용
특정 코드/문자열이 있는 위치 찾기Grep내용 기반 검색에 최적화
이름 패턴으로 파일 찾기Glob*.test.js 같은 경로 패턴 매칭
셸 명령 실행 (npm, git 등)Bashfind/grep/cat 등은 위 전용 도구로 대체
